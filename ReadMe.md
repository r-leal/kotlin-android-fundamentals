## Architectural patterns

Software architecture is the fundamental structure of a system, composed of its software elements, 
the visible properties of these elements, and the relationships between them.
Unlike pure code or implementation details, architecture focuses on high-level decisions that are 
difficult (and expensive) to change after the project begins.
